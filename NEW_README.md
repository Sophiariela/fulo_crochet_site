# Fulo E-commerce Project

## New Structure
- **app/**: Main application package
  - **routes/**: Blueprint-based routes (auth, public, admin, checkout, cart)
  - **services/**: Business logic and DB access
  - **templates/**: Domain-separated HTML files
  - **static/**: Organized CSS, JS, and images
- **config.py**: Application configuration
- **app.py**: Entry point

## How to run
1. Install dependencies: `pip install -r requirements.txt`
2. Configure `.env` file
3. Run: `python app.py`
