# Fulo Crochet

A full-stack e-commerce platform for an artisanal crochet clothing brand,
built entirely on Android using Termux.

## Live Demo

[fulo-crochet.onrender.com](https://fulo-crochet.onrender.com)

---

## Features

- Product catalog with real-time category filtering
- Images self-hosted via static/images
- Fully responsive, mobile-first design
- Minimalist aesthetic with Playfair Display typography

---

## Tech Stack

| Layer       | Technology                        |
|-------------|-----------------------------------|
| Backend     | Python 3 + Flask                  |
| Templating  | Jinja2                            |
| Frontend    | HTML5, CSS3, Vanilla JS (ES6+)    |
| Fonts       | Google Fonts                      |
| Hosting     | Render                            |
| Images      | Self-hosted via static/images     |

---

## Built on Android

This project was inittialy developed entirely on a mobile tablet using
[Termux](https://termux.dev/), a Linux terminal emulator for Android.And finnished on a laptop.
